
# DataStructureTutorial

Bu proje, **veri yapıları (Data Structures)** teorik bilgisini uygulamalı hâle dönüştürmek için hazırlanmıştır.  
C ve C++ dillerinde temel veri yapıları ve algoritmaların uygulamaları yer almaktadır ve Data Structure müfredatı kapsanacak şekilde geliştirilmesi planlanmaktadır. 

---

## 📌 Amaç

Bu repo, veri yapıları konusundaki teorik bilgilerin **pratik uygulamalara dönüştürülmesi** için oluşturulmuştur.  
Projede C++ dili ile:

- Tek bağlı listeler  
- Çift bağlı listeler  
- Yığın (Stack)  
- Kuyruk (Queue)  
- Diğer veri yapıları  

gibi temel veri yapıları örnek kodlarla gösterilmektedir. 

---

## 📁 Proje Yapısı

Typik bir klasör yapısı aşağıdaki gibidir:

```

DataStructureTutorial/
├─ LinkedList/              # Tek bağlı liste uygulamaları
├─ Doubly_LinkedList/       # Çift bağlı liste uygulamaları
├─ Stack/                   # Yığın yapısına örnek kodlar
├─ ...                     # Diğer veri yapılarına ait klasörler
├─ DataStructure.sln        # Visual Studio çözüm dosyası
└─ README.md                # Proje açıklaması

````

## 🚀 Nasıl Başlanır

1. Reposu klonlayın:
```bash
   git clone https://github.com/Burhan0664/DataStructureTutorial.git
````

   * `DataStructure.sln` dosyasını Visual Studio ile açabilirsiniz.
3. Kodu derleyip çalıştırın:

   * Her klasör altında örnek uygulamalar bulunmaktadır.
